Urutan Prosedur Impor Data (Data Import Sequence)Agar tidak terjadi error relasi referensi kunci (foreign key error) di ERPNext, proses impor data WAJIB dilakukan secara bertahap sesuai urutan berikut:• Tahap 1: Master Pengelompokan & Atribut: Impor file 01_Item_Group.csv, 02_Item_Attribute.csv, 05_Warehouse.csv, 06_Supplier_Group.csv, dan 08_Customer_Group.csv.• Tahap 2: Master Entitas & Item: Impor file 03_Item.csv, 04_Item_Price.csv, 07_Supplier.csv, dan 09_Customer.csv.• Tahap 3: Master Manufaktur & BOM: Impor file 10_Work_Center.csv, 11_Operation.csv, 12_Routing.csv, dan 13_BOM.csv.• Tahap 4: Transaksi Operasional: Impor file 14_Work_Order.csv hingga 20_Sales_Invoice.csv untuk mensimulasikan alur kerja end-to-end.5.
